# docs/manuales

Manuales del sistema.

## Qué debe ir aquí

| Archivo | Contenido | Responsable |
|---|---|---|
| `manual_usuario.docx` | Cómo usar cada pantalla según el rol (Analista, Aprobador y Administrador), con una captura por pantalla | José Pablo |
| `manual_instalacion.docx` | Cómo instalar en Windows 10: instalar Java, instalar MySQL, ejecutar el script, crear `config.properties` y abrir el programa | Los dos (HU-C01) |

Reglas:

- El manual de usuario sigue el orden de los procesos: planificar, ejecutar y controlar, evaluar y resultado final.
- Las capturas van en una subcarpeta `capturas/`, con nombres como `04_revision_entregables.png`.
